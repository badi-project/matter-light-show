L'ordre compte pour les palettes (la 1ʳᵉ couleur va à la 1ʳᵉ lampe…). Renomme, réordonne, ou exclus une lampe des shows.

Ajouter un appareil Matter

  1. Sur l'iPhone, app Maison : ouvre les réglages du pont Hue (ou d'une de ses lampes) et touche « Activer le mode de jumelage », puis copie le code à 11 chiffres.
  2. Si ce bouton n'existe pas (pont ajouté à Maison via HomeKit et non Matter) : app Hue › Réglages › Smart Home / Matter › génère un code d'appairage. C'est la seule étape qui passe par Philips : ensuite, tout le pilotage se fait en Matter.
  3. Colle le code ici dans les 15 minutes. Le Mac doit être sur le même réseau Wi-Fi que le pont.

Tes lampes restent dans l'app Maison : Matter permet plusieurs contrôleurs en même temps (« multi-admin »).

Comment ça marche

  1. Joue ta musique avec l'app Musique du Mac (ou les boutons ci-dessus) et choisis tes HomePod / enceintes dans Sorties AirPlay.
  2. Active la synchro. En Automatique, les couleurs viennent de la pochette du morceau (ou de son genre) et le style suit la musique : doux pour un morceau calme, plus vif pour un morceau rapide. Une playlist « Noël » ou « Halloween » lance les shows dédiés.
  3. Si tu choisis un show, ses couleurs sont gardées mais son rythme suit la musique : à chaque temps, un groupe de lampes change et la couleur se propage en vague dans la pièce.
  4. Pour tomber pile sur les temps, active le micro : il écoute quelques secondes et cale tout seul les lumières. Le tempo est aussi mesuré sur l'extrait du morceau fourni par Apple. Laisse cette page ouverte.

Réglages

Débit max vers le pont cmd/s

Le pont Hue relaie chaque commande Matter en Zigbee : au-delà d'environ 10 commandes par seconde, il met les suivantes en file d'attente et le show prend du retard. Augmente seulement si tout reste fluide.

Pour composer un show sans être chez toi : les lampes virtuelles n'apparaissent que dans l'aperçu.
